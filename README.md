# Turkish Chat Support

## Installation (custom repository)

1. Open the Dalamud Settings menu in game, either by typing `/xlsettings` in chat or with the Settings button at the bottom of the Plugin Installer.
2. Go to the Experimental tab.
3. In the Custom Plugin Repositories section, paste `https://raw.githubusercontent.com/ceeprus/ffxiv-turkish-chat/main/repo.json` into the empty box at the bottom. The first time, Dalamud shows a warning there; wait for its timer and click "Ok, I have read and understood this warning" to unlock the box.
4. Click the + button.
5. Click Save at the bottom right.

The plugin will then appear in the Plugin Installer, which you can open by typing `/xlplugins` in chat.
